# ECSE 420 — Parallel Computing

Coursework from ECSE 420 (Parallel Computing) at McGill University,
completed with a partner across three assignments. Each assignment
explores a different aspect of concurrent and parallel programming in
Java.

## Assignments

- [**a1/**](./a1) — Deadlock, the Dining Philosophers problem, and
  sequential vs. parallel matrix multiplication.
- [**a2/**](./a2) — Mutual exclusion algorithms: the Filter lock and
  Lamport's Bakery algorithm.
- [**a3/**](./a3) — Fine-grained concurrent data structures (a
  hand-over-hand locked linked list, a bounded queue) and an analysis of
  cache performance under different locking strategies.
